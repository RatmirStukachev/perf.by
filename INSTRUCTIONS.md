# Инструкция по запуску парсера и интеграции с сайтом

## 1. Описание
Вы просили создать программу-парсер на Python (Django), которая будет независимо скачивать товары с сайта "Сиб-инструмент" (со всех его категорий), парсить их цены, наличие, характеристики и фото, а затем отдавать вашему сайту на Laravel точно в таком же формате, в каком это раньше делал Zoomos.

В директории `parser_service` находится готовое решение:
- Это локальный веб-сервер на Python, который собирает информацию и имитирует API Zoomos.
- Ваш сайт на Laravel будет думать, что он обращается к Zoomos, но на самом деле будет скачивать данные из вашей новой программы.

## 2. Установка и запуск Python сервера (парсера)

1. Убедитесь, что у вас установлен Python (версии 3.10 или новее).
2. Перейдите в папку с парсером через терминал (командную строку):
   ```bash
   cd parser_service
   ```
3. Создайте виртуальное окружение и активируйте его (если вы на Windows):
   ```bash
   python3 -m venv venv_new
   venv_new\Scripts\activate
   ```
   *(Если вы на Linux/Mac, используйте: `source venv_new/bin/activate`)*
4. Установите необходимые библиотеки:
   ```bash
   pip install django djangorestframework beautifulsoup4 requests
   ```
5. Примените миграции базы данных и создайте администратора:
   ```bash
   python manage.py migrate
   python manage.py createsuperuser --username admin --email admin@example.com
   # (Вам будет предложено ввести пароль, например admin)
   ```
6. Запустите локальный сервер:
   ```bash
   python manage.py runserver 0.0.0.0:8000
   ```

Теперь ваш сервер работает по адресу: `http://127.0.0.1:8000`

## 3. Как запустить парсинг товаров?
1. Откройте в браузере админ-панель: `http://127.0.0.1:8000/admin/`
2. Войдите по умолчанию:
   - **Логин:** `admin` (или тот, что вы создали выше)
   - **Пароль:** ваш пароль
3. На главной странице админки вы увидите большую кнопку **"🚀 ЗАПУСТИТЬ ПАРСЕР ПОСТАВЩИКА"**. Нажмите на неё. Парсер запустится в фоновом режиме, скачает список категорий и всех товаров, их описания, характеристики и картинки, и сохранит в локальную базу (процесс может занять время, так как парсятся все товары с сайта).

## 4. Как переключить ваш сайт Laravel на новый парсер?

Вы просили **не менять** код проекта на GitHub. Поэтому вам нужно будет внести два небольших изменения самостоятельно на вашем сервере (там, где крутится Laravel):

### Шаг 1: Настройка ссылки API
Откройте файл `app/Services/ZoomosImportService.php` в вашем Laravel проекте.
Найдите три места (примерно строки 411, 437, 1093), где написано:
```php
$url = "https://api.zoomos.by/item/{$zoomosId}";
// и
Http::timeout(60)->get('https://api.zoomos.by/pricelist'...
// и
Http::timeout(60)->get('https://api.zoomos.by/categories'...
```
Поменяйте `https://api.zoomos.by` на адрес вашей запущенной программы `http://127.0.0.1:8000`.
Например:
```php
$url = "http://127.0.0.1:8000/item/{$zoomosId}";
```

*(Если Python-парсер будет запущен на другом сервере, укажите его реальный IP-адрес вместо 127.0.0.1)*

### Шаг 2: Настройка ключа (опционально)
Ключ `ZOOMOS_API_KEY` в вашем файле `.env` можно оставить любым. Новая Python-программа принимает запросы с любым ключом.

### Шаг 3: Запуск импорта на сайте
Теперь вы можете запускать команды импорта на вашем сайте точно так же, как вы это делали раньше:
```bash
php artisan zoomos:import-categories
php artisan zoomos:import
```
Они скачают все спарсенные товары и обновят ваш сайт!
