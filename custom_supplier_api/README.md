# Custom Supplier API (Zoomos Mock Server)

Это отдельное приложение на Django, которое имитирует работу API `zoomos.by`, но позволяет отдавать данные ваших собственных поставщиков.

## Как запустить

1. **Перейдите в папку проекта:**
   ```bash
   cd custom_supplier_api
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install django requests beautifulsoup4 lxml
   ```

4. **Примените миграции (создание структуры БД):**
   ```bash
   python manage.py migrate
   ```

5. **Создайте суперпользователя (администратора):**
   ```bash
   python manage.py createsuperuser
   # Следуйте инструкциям (имя пользователя, email, пароль)
   ```

6. **Запустите сервер разработки:**
   ```bash
   python manage.py runserver
   ```
   Сервер запустится по адресу `http://127.0.0.1:8000/`.

## Как парсить товары

1. Зайдите в админ-панель: `http://127.0.0.1:8000/admin/`
2. Авторизуйтесь под созданным суперпользователем.
3. Перейдите в раздел **Products** (Товары).
4. В правом верхнем углу вы увидите зеленую кнопку **"Спарсить ECO с tools.by"**.
5. При нажатии запустится скрипт, который обновит базу данных (пока добавлены тестовые данные бренда ECO). Вы можете расширить логику в файле `zoomos/management/commands/parse_eco.py`.

## Как запустить оба сайта (Laravel и Django) на локальном компьютере одновременно

Для того чтобы обновить цены в вашем магазине, используя новую программу, вам нужно запустить **два локальных сервера** одновременно, чтобы они могли общаться друг с другом.

Так как оба сайта будут работать на вашем компьютере (localhost), им нужны разные "порты" (грубо говоря, разные двери).

**Шаг 1: Запустите ваш Laravel магазин (как обычно)**
Обычно вы запускаете его командой:
```bash
php artisan serve
```
Он запустится по адресу: `http://127.0.0.1:8000`

**Шаг 2: Запустите новую Django программу на другом порту**
В новом окне терминала (не закрывая первое) перейдите в папку `custom_supplier_api` и запустите Django сервер на порту `8001` (или любом другом свободном):
```bash
source venv/bin/activate
python manage.py runserver 8001
```
Теперь Django программа работает по адресу: `http://127.0.0.1:8001`

**Шаг 3: Переключить Laravel-магазин на ваш новый Django сервер**
Теперь нужно сказать Laravel магазину, чтобы он забирал данные не у Zoomos, а у вашей новой программы (Django), которая крутится на `http://127.0.0.1:8001`.

В вашем Laravel-проекте (файл `app/Services/ZoomosImportService.php`) адреса `https://api.zoomos.by/...` прописаны жестко. Вам нужно их изменить (вы можете сделать это только локально и не отправлять эти изменения на GitHub).

Замените во всех функциях `ZoomosImportService.php` вызовы `https://api.zoomos.by/` на `http://127.0.0.1:8001/`.

Например, найдите функцию `fetchProducts` и замените:
```php
Http::timeout(60)->get('https://api.zoomos.by/pricelist', ['key' => $apiKey]);
```
На:
```php
Http::timeout(60)->get('http://127.0.0.1:8001/pricelist', ['key' => $apiKey]);
```

Сделайте то же самое для остальных запросов в `ZoomosImportService.php`:
* `fetchCategories` -> `http://127.0.0.1:8001/categories`
* `fetchBrands` -> `http://127.0.0.1:8001/dict/vendors/json`
* `fetchCharacteristics` -> `http://127.0.0.1:8001/dict/features/json`
* `fetchProductDetails` -> `http://127.0.0.1:8001/item/{$zoomosId}`

**Шаг 4: Обновление товаров**
1. Откройте админку Django (`http://127.0.0.1:8001/admin/`) и нажмите "Спарсить ECO с tools.by", чтобы загрузить данные в базу Django.
2. В Laravel запустите вашу обычную команду импорта из консоли (например, `php artisan zoomos:update-products` или `php artisan zoomos:import`), и она скачает данные из вашего Django сервера.

---
**Важно:** Этот код добавлен без изменения исходников Laravel, как вы и просили. Парсинг `tools.by` сейчас реализован в виде примера на 3 товара. Если потребуется глубокий парсинг всего сайта `tools.by`, потребуется дописывать обход пагинации в `parse_eco.py`.
