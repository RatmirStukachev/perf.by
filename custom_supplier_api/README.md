# Custom Supplier API (Zoomos Mock Server)

Это отдельное приложение на Django, которое имитирует работу API `zoomos.by`, но позволяет отдавать данные ваших собственных поставщиков.

## Как запустить

1. **Перейдите в папку проекта:**
   ```bash
   cd custom_supplier_api
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install django requests beautifulsoup4 lxml
   ```

4. **Примените миграции (создание структуры БД):**
   ```bash
   python manage.py migrate
   ```

5. **Создайте суперпользователя (администратора):**
   ```bash
   python manage.py createsuperuser
   # Следуйте инструкциям (имя пользователя, email, пароль)
   ```

6. **Запустите сервер разработки:**
   ```bash
   python manage.py runserver
   ```
   Сервер запустится по адресу `http://127.0.0.1:8000/`.

## Как парсить товары

1. Зайдите в админ-панель: `http://127.0.0.1:8000/admin/`
2. Авторизуйтесь под созданным суперпользователем.
3. Перейдите в раздел **Products** (Товары).
4. В правом верхнем углу вы увидите зеленую кнопку **"Спарсить ECO с tools.by"**.
5. При нажатии запустится скрипт, который обновит базу данных (пока добавлены тестовые данные бренда ECO). Вы можете расширить логику в файле `zoomos/management/commands/parse_eco.py`.

## Как переключить Laravel-магазин на ваш новый сервер

В вашем Laravel-проекте (файл `app/Services/ZoomosImportService.php`) адреса `https://api.zoomos.by/...` прописаны жестко (захардкожены). У вас есть 2 варианта:

### Вариант 1: Изменить URL в коде `ZoomosImportService.php`
Замените во всех функциях вызовы `https://api.zoomos.by/` на `http://127.0.0.1:8000/`.
Например, вместо:
```php
Http::timeout(60)->get('https://api.zoomos.by/pricelist', ['key' => $apiKey]);
```
Сделайте так:
```php
Http::timeout(60)->get('http://127.0.0.1:8000/pricelist', ['key' => $apiKey]);
```
*(То же самое сделать для `/categories`, `/dict/vendors/json`, `/dict/features/json`, `/item/`)*

### Вариант 2: Использовать подмену DNS (если сервер на Linux)
Добавьте строку в файл `/etc/hosts`:
```
127.0.0.1 api.zoomos.by
```
(При этом нужно будет настроить Django так, чтобы он работал по HTTPS или отключить проверку SSL в Laravel, так что Вариант 1 проще).

---
**Важно:** Этот код добавлен без изменения исходников Laravel, как вы и просили. Парсинг `tools.by` сейчас реализован в виде примера на 3 товара. Если потребуется глубокий парсинг всего сайта `tools.by`, потребуется дописывать обход пагинации в `parse_eco.py`.
